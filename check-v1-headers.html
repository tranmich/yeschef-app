How to Check V1 Usage

Method 1: Browser DevTools (Easiest)

  1. Press F12 to open Chrome DevTools
  2. Go to Network tab
  3. Use your app (load recipes, browse, etc.)
  4. Look for requests starting with /api/ (but NOT /api/v2/)
  5. Click on any request and check Headers tab
  6. Look for X-API-Deprecated: true

Method 2: Server Logs

  1. Look at your Python terminal where the server is running
  2. Watch for yellow warning messages like:
  3. ⚠️ DEPRECATED V1 ENDPOINT CALLED: /api/recipes -> Use /api/v2/recipes/user/{user_id} instead

Method 3: PowerShell Script

  1. Open PowerShell
  2. Run: .\monitor-v1-usage.ps1
  3. Follow the on-screen instructions

Expected Result

✅ No V1 deprecation warnings should appear!

Since we migrated all frontend code to V2, you should see:

  • All API calls use /api/v2/
  • No deprecation headers in responses
  • No deprecation warnings in server logs
