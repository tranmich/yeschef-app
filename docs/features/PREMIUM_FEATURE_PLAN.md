## 🎯 Executive Summary

### **Vision**
Create a fair, value-based tier system where free users can experience YesChef's core value (recipe management), while premium users unlock powerful collaboration and household features.

### **Business Model**
- **Free Tier:** Generous limits to attract users and enable viral growth
- **Premium Tier:** Family/community-focused features at affordable pricing
- **Target:** 5-10% conversion rate from free to premium

### **Key Differentiator**
Free users can **consume** (organize recipes, meal plan), while premium users can **share** (invite, collaborate, household management).

## 🎨 Tier Strategy

### **Free Tier: "Personal Chef"**
**Perfect for individual recipe management**

#### Core Philosophy:
- Generous limits (100 recipes, 5 spaces)
- Full access to recipe organization
- Can participate in communities
- URL import (strongest feature) unrestricted
- No artificial limitations on core value

#### Target User:
> "I just want to organize my own recipes and meal plan for myself."

#### Growth Mechanism:
- Can join collaborative spaces (but can't create/invite)
- Recipe sharing brings friends into ecosystem
- Natural upgrade path when needs grow

---

**Built for families and communities**

#### Core Philosophy:
- Remove all limits
- Unlock collaboration superpowers
- Enable household/community features
- Premium import methods (photo, voice)

#### Target User:
> "I cook for my family and want to collaborate with loved ones."

#### Value Proposition:
- Worth $4.99/month for family organization
- Price of one coffee = organized family meals
- Clear ROI for household managers

#### **Tier Middleware:**
```python
def check_tier_permission(user_id, permission):
    """
    Middleware to check if user's tier allows action
    """
    user = get_user(user_id)
    tier = user.tier or 'free'
    limits = TIER_LIMITS[tier]
    
    # Check permission
    if permission == 'add_recipe':
        if limits['max_recipes'] is None:
            return True, None
        
        if user.recipe_count >= limits['max_recipes']:
            return False, {
                'error': 'Recipe limit reached',
                'limit': limits['max_recipes'],
                'current': user.recipe_count,
                'upgrade_required': True
            }
    
    return True, None

# Apply to routes
@app.route('/api/recipes', methods=['POST'])
def add_recipe():
    user_id = get_current_user_id()
    allowed, error = check_tier_permission(user_id, 'add_recipe')
    
    if not allowed:
        return jsonify(error), 403
    
    # Proceed with recipe creation
```

```python
@app.route('/api/stripe/webhook', methods=['POST'])
def stripe_webhook():
    payload = request.data
    sig_header = request.headers.get('Stripe-Signature')
    
    try:
        event = stripe.Webhook.construct_event(
            payload, sig_header, webhook_secret
        )
    except Exception as e:
        return jsonify({'error': str(e)}), 400
    
    # Handle events
    if event['type'] == 'customer.subscription.created':
        handle_subscription_created(event['data']['object'])
    elif event['type'] == 'customer.subscription.deleted':
        handle_subscription_cancelled(event['data']['object'])
    elif event['type'] == 'invoice.payment_failed':
        handle_payment_failed(event['data']['object'])
    
    return jsonify({'success': True})
```

#### **Payment Flow:**
```javascript
import { useStripe } from '@stripe/stripe-react-native';

const handlePurchase = async (plan) => {
    const { initPaymentSheet, presentPaymentSheet } = useStripe();
    
    // 1. Create payment intent on backend
    const response = await fetch('/api/payment/create-intent', {
        method: 'POST',
        body: JSON.stringify({ plan }),
    });
    const { paymentIntent, ephemeralKey, customer } = await response.json();
    
    // 2. Initialize payment sheet
    const { error } = await initPaymentSheet({
        paymentIntentClientSecret: paymentIntent,
        customerEphemeralKeySecret: ephemeralKey,
        customerId: customer,
    });
    
    if (error) {
        Alert.alert('Error', error.message);
        return;
    }
    
    // 3. Present payment sheet
    const { error: paymentError } = await presentPaymentSheet();
    
    if (paymentError) {
        Alert.alert('Payment Failed', paymentError.message);
    } else {
        Alert.alert('Success', 'You are now premium!');
        // Refresh user tier
        await refreshTierStatus();
    }
};
```
