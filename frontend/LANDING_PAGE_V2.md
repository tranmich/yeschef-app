## 🚀 **How to Add Your Screenshots**

### **Step 1: Take Screenshots**
See `SCREENSHOT_GUIDE.md` for detailed instructions

### **Step 2: Save to Project**
```bash
# Create folder
mkdir frontend/public/images/screenshots

# Add your screenshots
# - app-recipe-grid.png
# - app-meal-plan.png
# - app-grocery-list.png
# etc.
```

### **Step 3: Update CSS**
Replace placeholder backgrounds with actual images:

```css
/* Example in LandingPage.css */
.screenshot-placeholder {
  background: url('/images/screenshots/app-recipe-grid.png') center/cover no-repeat;
  border: none; /* Remove dashed border */
}

.screenshot-placeholder span {
  display: none; /* Hide placeholder text */
}
```
