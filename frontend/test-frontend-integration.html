📚 Load Recipes

Endpoint: GET /api/v2/recipes/user/{userId}

  1. Navigate to /app (main app)
  2. Open browser DevTools console
  3. Look for "V2 API" in console logs
  4. Verify recipes load on page
  5. Check pagination info in console

🌐 Import from URL

Endpoint: POST /api/v2/recipes/import/url

  1. Click "📥 Import Recipe" in sidebar
  2. Select "From Web" tab
  3. Paste: https://www.allrecipes.com/recipe/23600/worlds-best-lasagna/
  4. Click "Import Recipe"
  5. Verify preview shows recipe data
  6. Click "✅ Save Recipe"

📝 Import from Text

Endpoint: POST /api/v2/recipes/import/text

  1. Click "📥 Import Recipe"
  2. Select "Manual Entry" tab
  3. Click "📋 Use Sample Recipe"
  4. Click "Import Recipe"
  5. Edit recipe if desired
  6. Click "✅ Save Recipe"

🗑️ Delete Recipe

Endpoint: DELETE /api/v2/recipes/{id}

  1. Find any recipe in the list
  2. Click the edit (✎) button
  3. Open console to see v2 endpoint log
  4. Confirm deletion dialog
  5. Verify recipe removed from list
